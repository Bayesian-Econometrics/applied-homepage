The economic question

Does averaging two plausible return models improve a sequence of honest predictive densities?

Derive before coding

Derive \(w_{j,t-1}\propto p(M_j)p(y_{1:t-1}\mid M_j)\) and \(p(y_t\mid y_{1:t-1})=\sum_jw_{j,t-1}p(y_t\mid y_{1:t-1},M_j)\). Explain why the score is the log of a mixture, not a mixture of logs.

Core assignment

  1. Compare an intercept-only model with an intercept-plus-predictor model using proper NIG priors.
  2. Begin with 40 observations, forecast the next observation, record its log score, and only then expand the sample.
  3. Plot cumulative BMA score minus the intercept-only benchmark score.
  4. Verify that model weights sum to one and show how using future outcomes would contaminate the exercise.

Submit your derivation, runnable code, and a short interpretation. State the prior convention, distinguish posterior uncertainty from simulation error, and explain one sensitivity check.

Reference implementation

The code implements the model above in a reproducible standalone example. Identify where each posterior parameter enters the calculation, then change one assumption at a time.

Show the reference implementation 
import numpy as np
import pandas as pd
from scipy import stats
from scipy.special import gammaln, logsumexp
import matplotlib.pyplot as plt

SEED, T, INITIAL = 2026, 120, 40
rng = np.random.default_rng(SEED)
x = rng.normal(size=T)
y = .2+.35*x+rng.normal(size=T)
designs = [np.ones((T,1)),np.column_stack([np.ones(T),x])]
rows = []
for t in range(INITIAL,T):
    evidence, forecasts = [], []
    for design in designs:
        X, target = design[:t], y[:t]
        K = X.shape[1]
        V0, a0, d0 = np.eye(K)*4, 3., 2.
        P0 = np.linalg.inv(V0)
        V1 = np.linalg.inv(P0+X.T @ X)
        b1 = V1 @ X.T @ target
        a1 = a0+t/2
        residual = target-X @ b1
        d1 = d0+(residual @ residual+b1 @ P0 @ b1)/2
        log_e = (-t/2*np.log(2*np.pi)+.5*(np.linalg.slogdet(V1)[1]-np.linalg.slogdet(V0)[1])
                 +gammaln(a1)-gammaln(a0)+a0*np.log(d0)-a1*np.log(d1))
        scale = np.sqrt(d1/a1*(1+design[t] @ V1 @ design[t]))
        evidence.append(log_e)
        forecasts.append(stats.t.logpdf(y[t],2*a1,loc=design[t] @ b1,scale=scale))
    log_weights = np.array(evidence)-logsumexp(evidence)
    assert np.isclose(np.exp(log_weights).sum(),1)
    rows.append({'time':t,'BMA':logsumexp(log_weights+forecasts),
                 'benchmark':forecasts[0],'predictor weight':np.exp(log_weights[1])})
scores = pd.DataFrame(rows)
scores['cumulative gain'] = (scores['BMA']-scores['benchmark']).cumsum()
print(scores.tail())
print(scores[['BMA','benchmark']].mean())

fig, ax = plt.subplots()
ax.plot(scores['time'], scores['cumulative gain'], color='steelblue')
ax.axhline(0, color='grey', lw=.8)
ax.set(xlabel='time', ylabel='cumulative log-score gain',
       title='BMA cumulative log-predictive score minus intercept-only benchmark')
plt.tight_layout()
plt.show()

fig, ax = plt.subplots()
ax.plot(scores['time'], scores['predictor weight'], color='darkorange', label='predictor model')
ax.plot(scores['time'], 1-scores['predictor weight'], color='steelblue', label='intercept-only model')
ax.set(xlabel='time', ylabel='posterior model weight', ylim=(0,1),
       title='Evolution of the BMA model weights over the backtest')
ax.legend()
plt.tight_layout()
plt.show()

Additional practice from the lecture

The following questions extend the backtest above.

  1. Rerun the backtest starting from INITIAL = 20 instead of 40, keeping everything else fixed, and report the final cumulative gain and the average predictor weight over the backtest. Explain why a shorter training start makes the early log scores noisier.
  2. Repeat the backtest with the coefficient prior variance V0 tightened to np.eye(K)*0.5 and loosened to np.eye(K)*20, and report the final cumulative gain in each case alongside the one already printed. Does a tighter coefficient prior on the predictor model help or hurt its case for a high posterior weight here?
  3. Derive, from \(w_{j,t-1}\propto p(M_j)p(y_{1:t-1}\mid M_j)\), why the two weights in this two-model backtest must sum to one at every \(t\), and confirm the assert in the reference code holds at every date rather than only at the final one.
  4. A portfolio manager can only use one model at a time but wants to choose which model to trust based on this backtest. Using the printed cumulative gain and the model-weight plot, explain at what point in the backtest the manager would have been better off overriding BMA and just using the predictor-only model, and what risk that override would have carried before that point in the sample.
