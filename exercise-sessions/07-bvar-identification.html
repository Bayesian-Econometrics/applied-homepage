The economic question

Which output responses remain plausible after imposing contractionary-policy signs?

Derive before coding

Derive the joint Normal coefficient conditional using column-wise vectorisation and an independent inverse-Wishart covariance prior. Then show that \(C=PQ\), with \(PP^\top=\Sigma\) and orthogonal \(Q\), leaves \(CC^\top\) unchanged. Restrict the policy-shock column to lower output and inflation and raise the rate at horizons 0–2.

Core assignment

  1. Fit the simulated three-variable system using the two-block Gibbs sampler.
  2. Draw one orthogonal rotation per retained parameter draw and retain those satisfying the signs.
  3. Plot posterior response bands and report the acceptance fraction.
  4. Relax the output restriction and explain the changes. Distinguish sampling uncertainty, identification uncertainty, and any imposed stability condition.

Submit your derivation, runnable code, and a short interpretation. State the prior convention, distinguish posterior uncertainty from simulation error, and explain one sensitivity check.

Reference implementation

The code implements the model above in a reproducible standalone example. Identify where each posterior parameter enters the calculation, then change one assumption at a time.

import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

SEED, T, M, ITER, BURN, H = 2026, 160, 3, 2200, 600, 10
rng = np.random.default_rng(SEED)
A = np.array([[.5,.1,-.1],[0,.6,-.1],[.1,.1,.4]])
series = np.zeros((T+1,M))
for t in range(T):
    series[t+1] = A @ series[t] + rng.normal(0,.5,M)
X, Y = np.column_stack([np.ones(T),series[:-1]]), series[1:]
K = X.shape[1]
b0 = np.zeros(K*M)
Vdiag = np.tile([10.,.3,.3,.3],M)
P0 = np.diag(1/Vdiag)
nu0, S0, Sigma = M+2, np.eye(M), np.eye(M)
accepted, covariance_draws = [], []
for s in range(ITER):
    inv_sigma = np.linalg.inv(Sigma)
    precision = P0 + np.kron(inv_sigma,X.T @ X)
    covariance = np.linalg.inv(precision)
    mean = covariance @ (P0 @ b0 + (X.T @ Y @ inv_sigma).ravel(order='F'))
    b = mean + np.linalg.cholesky(covariance) @ rng.standard_normal(K*M)
    B = b.reshape(K,M,order='F')
    residual = Y-X @ B
    Sigma = stats.invwishart.rvs(nu0+T, S0+residual.T @ residual, random_state=rng)
    if s < BURN:
        continue
    covariance_draws.append(Sigma.copy())
    rotation, triangular = np.linalg.qr(rng.standard_normal((M,M)))
    rotation *= np.sign(np.diag(triangular))
    impact = np.linalg.cholesky(Sigma) @ rotation
    responses = np.array([np.linalg.matrix_power(B[1:].T,h) @ impact[:,0]
                          for h in range(H+1)])
    for sign in [1.,-1.]:
        candidate = sign*responses
        if (candidate[:3,:2] < 0).all() and (candidate[:3,2] > 0).all():
            accepted.append(candidate)
            break
accepted = np.asarray(accepted)
assert len(accepted) > 0
band = np.quantile(accepted,[.16,.5,.84],axis=0)
print(f'Accepted rotations: {len(accepted)}/{ITER-BURN}')

recursive = np.array([np.linalg.matrix_power(B[1:].T,h) @ np.linalg.cholesky(Sigma)[:,0]
                      for h in range(H+1)])

fig, axes = plt.subplots(1,3,figsize=(11,3.2))
for j,name in enumerate(['output','inflation','rate']):
    axes[j].plot(range(H+1),band[1,:,j],color='steelblue',label='sign-restricted median')
    axes[j].fill_between(range(H+1),band[0,:,j],band[2,:,j],alpha=.2,color='steelblue',
                         label='68% band')
    axes[j].plot(range(H+1),recursive[:,j],color='darkorange',ls='--',label='recursive (Cholesky)')
    axes[j].axhline(0,color='grey',lw=.7)
    axes[j].set(title=name,xlabel='horizon',ylabel='response')
axes[0].legend(fontsize=8)
fig.suptitle('Policy-shock impulse responses: sign-restricted band vs. recursive path')
plt.tight_layout()
plt.show()
Accepted rotations: 98/1600

This reference solution conditions on the sign restrictions but imposes no additional stability restriction. Check the posterior eigenvalues before long-horizon interpretation. One proposed rotation per draw gives a joint parameter/rotation sample conditioned on admissibility; repeatedly searching until every parameter draw has an admissible rotation changes the implied weighting.

The chunk below reuses the stored posterior draws to ask how sensitive the accepted share is to the restriction horizon: imposing the signs at horizons 0–2 only, versus extending them to horizons 0–4.

def acceptance_share(horizon_span, n_check=400):
    hits = 0
    for Sigma_draw in covariance_draws[:n_check]:
        rotation, triangular = np.linalg.qr(rng.standard_normal((M,M)))
        rotation *= np.sign(np.diag(triangular))
        impact = np.linalg.cholesky(Sigma_draw) @ rotation
        responses = np.array([np.linalg.matrix_power(B[1:].T,h) @ impact[:,0]
                              for h in range(horizon_span+1)])
        for sign in [1.,-1.]:
            candidate = sign*responses
            if (candidate[:,:2] < 0).all() and (candidate[:,2] > 0).all():
                hits += 1
                break
    return hits/min(n_check,len(covariance_draws))

spans = [1,2,4]
shares = [acceptance_share(h) for h in spans]
print('Acceptance share by restriction horizon:',
      {f'0-{h}':round(s,3) for h,s in zip(spans,shares)})

fig, ax = plt.subplots()
ax.bar([f'0–{h}' for h in spans], shares, color='steelblue')
ax.set_xlabel('sign-restriction horizon window')
ax.set_ylabel('acceptance share')
ax.set_title('Longer restriction horizons accept fewer rotations')
plt.tight_layout()
plt.show()
Acceptance share by restriction horizon: {'0-1': 0.163, '0-2': 0.068, '0-4': 0.0}

Extending the restriction to more horizons is a stronger joint requirement, so it mechanically accepts a smaller share of proposed rotations: this is the identification uncertainty referred to above, made visible as a shrinking admissible set rather than a change in the underlying parameter posterior.

Additional practice from the lecture

The following questions extend the sign-restricted BVAR lab above.

  1. Re-run the sign-restriction search imposing the signs only at horizon 0 (instead of horizons 0–2) and again at horizons 0–4. Report the acceptance share in each case alongside the ones already printed, and describe how the width of the output band changes as the restriction window grows.
  2. Multiply the prior standard deviations Vdiag by ten (a much looser Minnesota prior) and rerun the sampler. Report the new acceptance share and the posterior median response of output at horizon 2, and explain why a looser coefficient prior changes how often a randomly rotated shock satisfies the signs.
  3. Derive, for a single retained coefficient draw, why \(CC^\top = \Sigma\) for any orthogonal \(Q\) in \(C = PQ\) with \(PP^\top = \Sigma\), and confirm numerically that the accepted impact matrices in the reference code all satisfy impact @ impact.T equal to the corresponding Sigma draw to numerical precision.
  4. A trading desk wants to know how much of the estimated output response is really pinned down by the sign restrictions rather than by the data. Using the acceptance shares from question 1, argue whether the desk should treat the 0–4 horizon result as more or less reliable than the 0–2 horizon result, and connect the answer to the price of imposing more identifying assumptions than the data alone can adjudicate.
